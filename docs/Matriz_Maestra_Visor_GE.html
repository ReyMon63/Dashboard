siguiente nivel

Dominio propio + login real (Netlify)

El plan guardado para dar el salto “profesional”: mover el visor a un dominio tuyo (sin github/netlify a la vista) y un login real por invitación por correo.

  • Comprar dominio (ej. Cloudflare Registrar) y usar un subdominio tipo visor.midominio.com.
  • Hospedar en Netlify + activar Netlify Identity (registro solo por invitación).
  • Conectar el dominio por DNS (CNAME) y dejar la URL secreta actual como respaldo.

Guardado en la nota “PENDIENTE — Visor GE: dominio + login Netlify” y en el archivo de guía. Frase para reactivarlo: “montemos el login de Netlify”.
